# 유물 자동 각인 모듈

## 목적

통합 매크로의 `유물` 탭은 사용자가 선택한 스탯 4개로 미장착·미각인 유물을 자동 각인한다. 완성된 유물의 스탯 합이 사용자가 설정한 목표에 도달할 때까지 다음 유물을 반복한다.

이 모듈은 **자동 각인만** 담당한다. 장착, 해제, 분해, 초기화는 자동으로 실행하지 않는다.

## GUI

- 위치: `재전직 / 유물 / 레어맵` 첫 번째 행
- 스탯: 힘, 생명, 지능, 정신, 속도, 행운 중 정확히 4개
- 목표 스탯 합: 완성 유물의 선택 스탯 4개 합계가 이 값 이상이면 종료
- 스탯의 체크 순서는 동률 우선순위로 기억된다. 단, 속도가 선택됐다면 속도가 항상 동률 최우선이다.

## 자동 각인 순서

1. `캐릭` → `유물 · 룬`으로 이동하고 유물 페이지를 DOM으로 확인한다.
2. `해제` 버튼이 있는 장착 중 유물은 건드리지 않는다.
3. 화면 위쪽의 첫 `각인 시작` 버튼을 선택한다.
4. `각인할 스탯 설정` 대화상자 안에서 설정된 4개만 누른다.
5. 매 회차마다 DOM에서 현재 레벨을 다시 읽는다.
6. 선택한 4개 중 가장 낮은 스탯을 주 슬롯으로 선택한다.
7. 최저 레벨이 동률이면 `속도` → 나머지 GUI 선택 순서로 판단한다.
8. `각인 진행 1,000,000 골드`를 누르고, 남은 횟수가 정확히 1 감소했는지 확인한 뒤 다음 회차로 넘어간다.
9. 8회차 완료 대화상자에서 `확인`을 누르기 **전** 스탯 4개의 합을 계산한다.
10. `합계 < 목표`면 `확인`만 눌러 완료창을 닫고 다음 미각인 유물로 반복한다.
11. `합계 >= 목표`면 완료창을 그대로 남기고 매크로를 종료한다.

## DOM 안전 규칙

- 화면 좌표를 사용하지 않는다.
- 버튼은 역할과 정확한 표시 문구로 찾는다.
- 대화상자 내부 버튼은 해당 대화상자로 검색 범위를 제한한다.
- 필수 요소가 정확히 1개가 아니면 클릭하지 않고 오류로 정지한다.
- 각인 후에는 횟수·레벨 변경을 DOM으로 확인해야 다음 클릭을 허용한다.
- 통합 매크로 GUI(`#lrm-panel`)는 게임 DOM 검색에서 제외한다.

## 실전 확인 예시

2026-08-22에 크롬의 라니스 실제 유물 DOM으로 다음을 확인했다.

- 선택 스탯: 지능, 정신, 속도, 행운
- 완료 결과: 지능 6, 정신 7, 속도 7, 행운 6
- 합계: 26
- 완료창의 `확인`을 누르기 전에 합계를 정상 계산할 수 있음을 확인했다.
